# Screen patterns

The home screen is one decision flow:

1. add links or files;
2. add the batch to the queue;
3. follow independent item progress;
4. open completed text.

The result screen is one document flow:

1. read or copy the text;
2. review uncertain regions with synchronized media;
3. edit with automatic save;
4. export the needed format.

Every screen models loading, empty, success, expected error, unexpected error,
and reconnecting states.
