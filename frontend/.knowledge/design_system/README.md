# Rune design system

Rune is calm, warm, precise, and local. The interface borrows Buffer's friendly
paper surfaces, spacing, and restrained mint emphasis while keeping Rune's own
monochrome identity.

- [Typography and spacing](typography_and_spacing.md)
- [Components](components.md)

The primary action must be obvious within five seconds. Secondary technology
details remain available without competing with the source, queue, or text.
