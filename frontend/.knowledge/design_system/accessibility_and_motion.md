# Accessibility and motion

- Meet WCAG AA contrast.
- Preserve visible `focus-visible` treatment.
- Associate labels, hints, and errors with controls.
- Give icon-only actions an accessible name.
- Use native semantic elements before ARIA.
- Announce queue success and failure in scoped live regions.
- Do not announce every progress percentage.
- Do not communicate status or review confidence through color alone.
- Preserve reliable keyboard order through composer, queue, player, text, and exports.
- Use short state transitions and respect `prefers-reduced-motion`.
- Avoid entrance animation that delays the primary action.
