# Typography and spacing

Figtree owns display, body, navigation, labels, and controls. Geist Mono is
reserved for timestamps, durations, file details, identifiers, and technical
status.

- Hero: responsive 44–64 px, tight tracking, short line length.
- Page title: 28–36 px.
- Panel title: 18–22 px.
- Product copy: 15–18 px.
- Labels and metadata: at least 13 px.

Use the Tailwind spacing scale. Align composer, queue, and result edges to one
content grid. Increase whitespace around the primary action and reduce density
only inside repeated queue rows.
