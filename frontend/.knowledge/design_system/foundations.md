# Foundations

- Begin with the user's next action, not decoration.
- Keep one dominant action per step.
- Use type and spacing before color or shadow.
- Show local processing as a concrete status, not a vague privacy claim.
- Keep queue stages understandable without logs.
- Put readable transcript text before model details.
- Remove controls that do not help the current task.
- Support Light, Dark, and System as one component system.
