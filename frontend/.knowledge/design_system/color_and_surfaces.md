# Color and surfaces

| Role | Light | Dark |
| --- | --- | --- |
| Canvas | `#FEFDFB` | `#0D1211` |
| Surface | `#FFFFFF` | `#171E1C` |
| Raised | `#FFFFFF` | `#202825` |
| Text | `#213130` | `#F2F4F1` |
| Muted text | `#626965` | `#A6AFAB` |
| Border | `#D7D5D2` | `#34403C` |
| Primary | `#B0EC9C` | `#B0EC9C` |
| Primary ink | `#14201E` | `#0D1211` |

Mint is a bounded interaction color. Success, warning, danger, information, and
review confidence use separate semantic roles and always include a text or shape
cue.
